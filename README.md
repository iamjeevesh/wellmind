🌿 WellMind — Student Wellness & Burnout Support App

An AI-powered wellness companion designed to help students manage stress, burnout, and academic pressure.


What is WellMind?
WellMind is a full-stack web application that gives students a safe, calming space to track their mental wellness, reflect on emotions, and get supportive guidance from an AI companion named Sage.
It is not a medical tool — it is a wellness and productivity support app built with care for student wellbeing.

Features - Description
🤖 AI Chat (Sage) - Emotionally supportive AI wellness companion
📊Burnout Score - Auto-calculated burnout risk from daily check-ins
✅ Daily Check-in - Track mood, stress, energy, and sleep every day
📔 Private Journal - Write freely with gentle AI reflections
🍅 Pomodoro Timer - Focus sessions with study tracking
💡 Insights - Personalized wellness recommendations
📈 Mood Trends - Beautiful charts showing your wellness over time
🌙 Dark Mode - Calming dark and light themes

Tech Stack
Frontend - Next.js, Tailwind CSS, Recharts
Backend - FastAPI (Python)
Database - PostgreSQL
AI - Groq (Llama 3.3) / OpenAI
Auth - Clerk
